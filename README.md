# Portafolio · Cesar Enrique Uc Aguilar

Portafolio hecho con React + Vite.

## Ejecutar
    npm install
    npm run dev

## Personalizar
Las demos de los trabajos están en `public/demos/`. Edita `src/data.js`: tus enlaces (GitHub, LinkedIn, correo) y, en cada proyecto, agrega `repo:` y/o `demo:` con su URL. Los campos vacíos no se muestran.

## Publicar
**Vercel:** sube el repo a GitHub, entra a vercel.com, "Add New Project", elige el repo y despliega (detecta Vite solo).
**GitHub Pages:** `npm run deploy` y activa Pages en Settings > Pages con la rama `gh-pages`.
